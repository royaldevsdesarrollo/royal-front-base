# Skills instaladas

Este documento describe las skills disponibles en `.agents/skills/`. Las instrucciones
operativas y convenciones del proyecto se encuentran en [`AGENTS.md`](../AGENTS.md).

## `frontend-architecture`

- **Origen:** [`we-are-singular/skills`](https://github.com/we-are-singular/skills)
- **Descripción:** guía de arquitectura frontend para proyectos TypeScript. Cubre límites entre
  capas, ownership de datos, organización modular, estado, acceso a APIs, formularios, estilos y
  pruebas.

## `vercel-react-best-practices`

- **Origen:** [`vercel-labs/agent-skills`](https://github.com/vercel-labs/agent-skills)
- **Descripción:** recomendaciones de rendimiento para React. Incluye reducción de waterfalls,
  optimización de bundles, fetching, renders, efectos y patrones modernos de React 19.

## `vercel-composition-patterns`

- **Origen:** [`vercel-labs/agent-skills`](https://github.com/vercel-labs/agent-skills)
- **Descripción:** patrones de composición escalables para React. Trata APIs de componentes,
  compound components, providers, variantes explícitas y separación entre estado e interfaz.

## `shadcn`

- **Origen:** [`shadcn-ui/ui`](https://github.com/shadcn-ui/ui)
- **Descripción:** conocimiento sobre componentes, registros, presets, composición, estilos y
  uso de la CLI de shadcn.

## `web-design-guidelines`

- **Origen:** [`vercel-labs/agent-skills`](https://github.com/vercel-labs/agent-skills)
- **Descripción:** criterios para revisar calidad visual, UX, responsive design, accesibilidad,
  navegación, formularios, estados interactivos y consistencia de interfaces web.

## `webapp-testing`

- **Origen:** [`anthropics/skills`](https://github.com/anthropics/skills)
- **Descripción:** herramientas de Playwright para interactuar con aplicaciones web locales,
  verificar flujos funcionales, capturar screenshots y consultar logs del navegador.

## `systematic-debugging`

- **Origen:** [`obra/superpowers`](https://github.com/obra/superpowers)
- **Descripción:** proceso sistemático para diagnosticar bugs, fallos de pruebas y
  comportamientos inesperados mediante evidencia, aislamiento e identificación de la causa raíz.

## `verification-before-completion`

- **Origen:** [`obra/superpowers`](https://github.com/obra/superpowers)
- **Descripción:** disciplina de verificación que exige evidencia reciente antes de afirmar que
  un cambio está terminado, corregido o funcionando.
